# Граф кода (модуль `graph`)

Хук `graph.py` на старте сессии (startup, resume, compact, clear) сверяет граф проекта с кодом. Свежий — одна строка в контекст с указанием на `docs/GRAPH.md`. Устарел или его нет — запускает сборку отдельным процессом и сразу возвращается: старт сессии не ждёт. Сборка проекта в 200 файлов занимает около 0,3 с, хук — около 0,1 с.

Только стандартная библиотека Python: ничего не ставит и не копирует чужого кода.

## Что строится
- `docs/GRAPH.md` — одна-две страницы для модели: области проекта и связи между ними, самые используемые файлы, самые вызываемые функции, файлы по областям. Не больше 160 строк.
- `.claude/combine/graph.json` — полный граф для запросов.

Слои:
- **файлы:** импорты TS/JS/Python, `#include "…"` в C/C++;
- **символы:** определения и вызовы. Python — точно, через `ast`. TS/JS/C — по скобкам тела и именам: вызов сопоставляется с определением по имени, поэтому одноимённые функции в разных файлах сливаются, а вызовы через объект (`x.f()`, `p->f()`) не видны вовсе.

## Запросы
```bash
python .claude/combine/graph/query.py users <файл>     # кто импортирует/включает
python .claude/combine/graph/query.py deps <файл>      # что импортирует сам
python .claude/combine/graph/query.py callers <имя>    # кто вызывает
python .claude/combine/graph/query.py calls <имя>      # что вызывает
python .claude/combine/graph/query.py find <имя>       # где определено
```
`<файл>` можно указывать хвостом пути (`ports/light.ts`). При глобальной установке путь `~/.claude/combine/graph/query.py`; точный путь пишется в шапке `docs/GRAPH.md`.

## Когда граф считается устаревшим
Метка сборки: `HEAD` и список изменённых и новых файлов (`git status`) с размером и временем изменения. Файлы графа и каталог `.claude/` не учитываются. Без git метка — только список файлов.

## Включение и выключение
По умолчанию включён. Выключить: `python tools/sync.py --target <проект> --without graph` или `COMBINE_DISABLE=graph` (входит и в `all`).

## Не проверено
Большие репозитории (тысячи файлов): время сборки и размер `graph.json`; монорепозитории с одноимёнными функциями во многих пакетах; Windows без `git` в PATH; облачная сессия; экономия токенов на деле.
