# M5. Su-field Interaction Model

Model two substances and a field/action: `S1 —F→ S2`. For AI, substances may be data, artifacts, agents, or components; F is the actual interaction/tool/prompt/signal. Name the object and the directly acting tool, not an abstract "system".

Mark the action useful, insufficient `—F(weak)→`, harmful `—F−→`, or absent. State evidence for the classification.

These are **repair heuristics inspired by standards**, not a reproduction of the 76 standards:
- Incomplete model: add the missing interaction using an available tool/resource (P10/P24).
- Insufficient useful action: change parameters (P35), strengthen only the bottleneck (P38), or use a qualitative state change (P36).
- Harmful action: remove the harmful link while preserving the useful one (P2), isolate it (P39), or turn the harm into a resource (P22).
- Poorly controllable action: introduce a responsive intermediary/substance S3, feedback (P23), or a measuring intermediary (P24).
- Excess complexity: simplify/remove the intermediary or change the interaction class (P28), rather than stacking wrappers.

Gate: output one model, its deficiency, one repair, and the expected observable effect. Verify with A9; if resources are missing, continue with A5.
