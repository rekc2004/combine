# M7. Function Analysis and Trimming

Describe functions as **action + object**, then identify the function carrier. Do not confuse a component with its function.

| Element/carrier | Useful function and adequacy | Harmful function | Cost/evidence |
|---|---|---|---|
| ___ | Adequate / insufficient / excessive | ___ | ___ |

Adequacy rates delivery of a **useful** function; it is not a rating for harmful functions.

Prioritize:
1. Eliminate or redirect harmful functions while preserving required useful functions.
2. Trim excessive/low-value functions: remove their carrier, transfer the useful function to an existing resource, or let the object/environment perform it.
3. Strengthen insufficient useful functions only after trimming; P35/P38 are options, not defaults.

Ideality is a qualitative direction here: more required useful function with less cost and harm. Do not report a numeric ratio unless units and measurements are meaningful.

Gate: produce a trim/strengthen list and identify any useful function that must survive. Use A3 for an ideal target and A9 to check that trimming did not move harm elsewhere.
