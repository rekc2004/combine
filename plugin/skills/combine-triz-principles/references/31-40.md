# Principles 31–40

| № | Principle | AI-task transformation |
|---|---|---|
| 31 | Porous materials | Add exchange pores or use an existing porous structure: extension points, hooks, sampling channels, or sparse interfaces through which working interactions pass. One-way logging is P32. |
| 32 | Color changes | Change visibility/transparency or add a marker: highlight assumptions, risk, provenance, and unverified claims without changing the underlying object. |
| 33 | Homogeneity | Make interacting parts homogeneous or compatible: shared formats and conventions at the boundary, while allowing different internal implementations. |
| 34 | Discarding and recovering | Remove spent parts and restore/regenerate reusable ones: compact state, rebuild an index, replace a consumable component; verify that needed information survives. |
| 35 | Parameter changes | Change a parameter of object/environment: chunk size, thresholds, temperature/effort where supported, or another measurable control knob. |
| 36 | Phase transitions | Use a qualitative state change at a threshold and its special effect: atomic commit/rollback, quorum, circuit breaker, hot/cold cache. Arbitrary workflow modes are P15. |
| 37 | Thermal expansion | Use controlled expansion/contraction, including different rates between parts: expand search/context under uncertainty and contract it as evidence converges; measure the changed scope. |
| 38 | Strong oxidants | Intensify only the stuck process with a more active resource: stronger model/effort where supported, or a stronger verifier/tool/main-session pass otherwise. Do not intensify routine work. |
| 39 | Inert atmosphere | Replace a reactive environment with a neutral/protective one: sandbox, isolated context, separate branch, or removal of interfering inputs. |
| 40 | Composite materials | Combine heterogeneous components so each supplies a needed property: cheap+strong models with verification, human+AI, symbolic+probabilistic methods. |

Gate: phase, expansion, and intensification must describe an observable system change; avoid decorative physical metaphors.
