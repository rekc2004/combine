# A10–A11: Apply and Learn

## A10. Use the verified answer
- Identify required changes in the supersystem and neighboring interfaces.
- Check whether the changed system can serve a new useful function.
- State the reusable principle and test direct and inverse transfer to neighboring tasks.
- For a broadly reusable result, optionally vary structural/field dimensions or scale toward zero/infinity to find other implementations.

Do not generalize from an unverified demonstration.

## A11. Analyze the route
Compare the actual route with the staged ARIZ route:
- which formulation or resource unlocked the answer;
- which step was skipped or repeated and why;
- what evidence verifies the result;
- what remains unverified.

Record one compact entry in TASK.md Decisions and one in Not verified/known limits when needed. Return to Combine Closing; do not create a separate TRIZ report by default.
