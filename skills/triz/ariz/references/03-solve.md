# A5–A7: Resources, Knowledge, Separation

## A5. Mobilize resources
Search in order: tool/object resources → task environment → supersystem. Prefer existing resources for the mini-task.

Include:
- OZ/OT and unused time before, during, and after conflict;
- unused data, formats, logs, history, tests, indexes, idle capacity;
- waste/harmful factors and their possible useful effect;
- derived resources (summary, decomposition, transformed state) and "void" (empty slot, absent component, removed dependency);
- one multi-screen view when stuck: supersystem/system/subsystem before/during/after.

Use only resources that are actually available or cheaply derivable; label assumptions.

## A6. Use the knowledge base
Choose one source at a time:
- the relevant range in `combine-triz-principles`;
- an analogous already solved task, inside or outside the domain, matched by function/contradiction rather than surface words;
- M5 for a missing/insufficient/harmful interaction;
- prior verified decisions in TASK.md and the project knowledge base.

Physical effect catalogues are domain-specific extras, not part of the base route.

## A7. Eliminate the contradiction
Try separation:
1. **Time:** S during one phase, ¬S during another.
2. **Space/structure:** S in one part, ¬S in another.
3. **Condition:** S under one trigger, ¬S otherwise.
4. **System level:** S for the whole, ¬S for elements, or vice versa, including the microlevel.

Optional depth check: describe the anti-system/worst solution to expose a hidden assumption.

Gate: write 2–3 resource-linked moves and select one for A9. If none satisfies IFR, read `04-reframe-check.md` for A8; otherwise go directly to its A9 check.
