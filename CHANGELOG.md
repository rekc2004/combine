# Changelog

## 0.3.0 (2026-10-09): роли, **не проверено экспериментом**
- Принцип «сильная модель дирижирует, не делает всё сама»: основная сессия Opus (рекомендуется, medium) ставит задачи, пишет спецификации, ревьюит и собирает; код пишет `builder` (Sonnet) по спецификации; новая роль `verifier` (Sonnet, low) делает независимую приёмку; `architect` только для критичных спецификаций и модели угроз, без инструментов для реализации; `scout` и `skeleton` без изменений по моделям.
- Шаблон спецификации `core/templates/SPEC.md` (ставится в проект как `.claude/combine/SPEC.md`).
- Правила делегирования в `pipeline.md`: лимиты отчётов, дирижёр не читает большие файлы и логи, не больше двух кругов правок, вложенные вызовы субагентов запрещены до проверки в облаке.
- Ключ `main_session` в `core/models.json` (не агент, для него файл не создаётся).
- Экономия на малых этапах не гарантирована; чтобы принять решение окончательно, нужны эксперименты (вложенность в облаке, сравнение вариантов).
